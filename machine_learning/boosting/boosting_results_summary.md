# Boosting Models Results Summary

This analysis evaluated three different boosting machine learning models to predict which team would win each round in Counter-Strike 2 matches. The study used data from multiple professional CS2 matches, analyzing 2,507 individual game state snapshots that were aggregated into 270 complete rounds. The data included detailed information about each round such as how much money each team had spent on equipment, how many players were still alive on each side, the total health and armor of each team, what types of weapons each team possessed (including powerful sniper rifles like AWPs and standard rifles), whether the bomb had been planted, and how much time remained in the round. These features were chosen because they represent the current state of the game at any given moment, which makes them useful for predicting outcomes rather than just describing what already happened.

The models were trained on 216 rounds and tested on 54 rounds to ensure they could make accurate predictions on new, unseen data. Three different boosting algorithms were tested: AdaBoost, Gradient Boosting, and XGBoost, with each model tested using multiple different configurations to find the best settings. The results showed that both AdaBoost and XGBoost performed exceptionally well, each achieving 83.33% accuracy in predicting the round winner, meaning they correctly predicted the outcome in about 5 out of every 6 rounds. Gradient Boosting also performed well with 79.63% accuracy, correctly predicting about 4 out of every 5 rounds. The best performing configuration for AdaBoost used 50 decision trees with a learning rate of 1.0, while the best XGBoost configuration used 50 trees with a learning rate of 0.1 and a maximum depth of 3 levels. These results demonstrate that boosting models are highly effective at learning patterns from game state data to predict round outcomes, with the models successfully identifying which team had the advantage based on factors like equipment value, player count, and weapon quality. The high accuracy rates suggest that the features used capture meaningful information about team advantages that translate into round victories, making these models potentially useful for real-time game analysis or strategic insights.
